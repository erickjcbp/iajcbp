# iajcbp: estrutura e comandos

| Pasta | Finalidade |
| --- | --- |
| `api/` | Funções do servidor; nome exigido pela hospedagem |
| `arte-escala/` | Geração da arte da escala |
| `coletor/` | Rotinas de coleta |
| `criar-logins/` | Geração de acessos e guias |
| `db/` | Scripts e regras do banco |
| `docs/` | Documentação e decisões |
| `entregas/` | Arquivos entregues e materiais de apoio |
| `midia/` | Imagens e sons usados pelas telas |
| `projetos/` | Aplicativos internos da paróquia |

## Comandos disponíveis

- `npm run test`
- `npm run provar-regras`
- `npm run provar-telas`

As instruções do Claude permanecem em `CLAUDE.md`, quando presente. Os `LEIA-ME.txt` removidos podem ser recuperados pelo registro da organização local.
