O que é isto?
-------------
Anotações pontuais, com a data no nome. NÃO são a lista de
pendências (essa é docs/pendencias.md) nem o histórico (esse é
docs/pendencias-fechados.md).

São recados que fizeram sentido num dia específico e foram
guardados para o caso de alguém perguntar depois.

Se um bilhete disser "apagar em tal data", é para apagar mesmo
quando a data chegar — foi combinado assim com o dono.
